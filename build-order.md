# Build order in Webflow

Each step teaches one graded skill. Sequence matters.

1. **Variables** — colour, typography, size, space groups. Set Variable Modes for tablet, mobile landscape, mobile portrait.
2. **Tag selectors** — style H1–H6, paragraphs, all links, lists, blockquotes, figures, figcaptions using Variables. Body carries the primary font; secondary fonts go on individual tags.
3. **Style Guide page** — build it third, not last. It's your visual regression test.
4. **Naming convention** — one format, never deviate. Combo classes max 3 levels, 3–4 per element.
5. **Components** — nav, footer, CTA band. Props and style variants, not duplicated structures.
6. **Home page** — assembled from real components.
7. **CMS** — Origins and Brew guides collections. Title Case names, singular slugs, sentence-case field names, help text on every field, 3–7 items each.
8. **Ecommerce** — 8 products, 2 categories, variants on the coffees. Then Cart, Checkout, PayPal checkout, Order confirmation. No preloaders on Product, Category, Checkout, Order confirmation.
9. **GSAP interactions** — last, once structure is stable. Delete every unused interaction.
10. **Responsive pass** — five breakpoints, target ≤2 bugs.
11. **PageSpeed** — SEO 70+, Performance 51+, Best practices 51+, Accessibility 70+.

## Hard constraint

**Never touch Ecommerce settings.** No business address, shipping method, tax setting, or payment provider. A business address cannot be removed once added.

## After the site is live

Apply at `webflow.com/templates/applications`. Lead with Cadence. Reference the 200+ Wix and 20+ WordPress builds as production track record — the application assesses customer empathy and support availability, and that history evidences both.

Post the build publicly as you go. Organic Marketplace discovery is explicitly a weak strategy; the audience is what drives traffic to every launch, and it takes the same months you'll spend learning Webflow.
